ultimate audio processing plugin for mixing/mastering with unique/rare features:

modular system;
internal routing system with parallel and serial processing paths;
internal osc control for almost all parameters;
each module can have up to 6 bands.

'tls' (tools) module:
static delay with a negative-delay option;
independent phase rotation for each channel;
shear operation;
independent mid and side balance controls;
four types of rectification;
720-degree orthogonal rotation.

'eql' (equalizer) module:
up to 64 bands;
bell, shelf, and flat-tilt phase types.

'fft' (dynamic bin) module:
spectral and correlation processing in a single module
(with separate signed, phase, and frequency processing);
dual-mono mode for spectral processing;
downward and upward processing;
adaptive threshold.

'dyn' (dynamics) module:
independent half-wave processing;
one-knob tension control;
adaptive threshold.

'trs' (transient) module:
synced hold/release;
one-shot control.
